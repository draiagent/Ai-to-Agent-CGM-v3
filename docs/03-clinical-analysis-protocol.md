# CGM 臨床分析協定（v1）

## 1. 分析目的

以一致的操作型定義描述餐後血糖反應，供個人生活型態觀察與控制比較。這些指標不是疾病診斷，也不能替代專業醫療判斷。

## 2. 時間軸

- `T0`：使用者確認的實際開始進食時間。
- 基準窗：`T0-15` 至 `T0-5` 分鐘。
- 主要觀察窗：`T0` 至 `T0+120` 分鐘。
- 延伸觀察窗：`T0` 至 `T0+180` 分鐘。

基準使用中位數，降低單一感測雜訊的影響。

## 3. 指標定義

### Baseline

`median(CGM[T0-15, T0-5])`

### ΔPeak

`max(CGM[T0, T0+180]) - baseline`

### Time to Peak

`time_of_max - T0`

### iAUC

Wolever 增量法（`iauc_method = "wolever_incremental"`）：只計算基準以上的面積，以梯形法積分。當相鄰兩點跨越基準時，僅取在基準之上的三角形面積；基準以下的面積忽略，不做扣減。同時報告計算窗長（`iauc_120`、`iauc_180`）與單位（mg/dL·min）。

### Recovery Time

v1 預設定義為：餐後曾上升超過基準 10 mg/dL 後，回到 `baseline ± 5 mg/dL`，且連續維持至少 15 分鐘的最早時間。所有門檻均應版本化，不得在不同報告中任意變更。

## 4. 資料品質

### A_CLEAN

- 基準窗至少有兩個有效點。
- 180 分鐘資料覆蓋率至少 80%。
- 餐後三小時無其他熱量攝取。
- 無已知感測器異常。
- 沒有未記錄、足以改變反應的運動。

### B_CONTEXTUAL

資料可解讀，但存在點心、飲料、餐後活動、睡眠不足、壓力、前餐未恢復或輕度缺值等干擾。可用於真實世界觀察，不宜單獨做控制比較。

### X_EXCLUDED

時間不確定、CGM覆蓋不足、感測器暖機／失效、疑似壓迫性低值、重大未記錄攝取或其他使指標不可信的情形。

## 5. 因果與重複性

- 單次結果只稱為觀察。
- 相似餐食至少 2–3 次才稱為初步趨勢。
- 若要比較改善效果，每次只變更一個主要因素。
- 報告需同時呈現反例與資料品質，不只挑選成功案例。

## 6. 安全升級

本系統不得自行決定急症處置。若使用者出現症狀或 CGM 顯示持續、嚴重異常，應提示其依醫囑使用指尖血糖確認，並聯絡合格醫療人員或所在地緊急醫療服務。不得根據本系統自行調整藥物或胰島素。

## 7. CGM 變異與範圍面板（v3）

除單餐指標外，`scripts/metabolic_panel.py` 依 2019 International Consensus on Time in Range 產生期間層級的面板：

- **平均血糖、GMI**：整體暴露量與估算 A1c。
- **CV%**：血糖變異係數；**< 36% 視為穩定**，用詞為「血糖反應彈性」，不使用「代謝彈性」（後者嚴格定義需 indirect calorimetry）。
- **TIR 70–180 / TBR < 70、< 54 / TAR > 180、> 250**：範圍內／低／高時間佔比。
- **隔夜穩定度**：當地時間 00:00–06:00 的平均與 CV。

### 低血糖安全事件

`< 70 mg/dL`（Level 1）與 `< 54 mg/dL`（Level 2）逐筆列出，**獨立於餐後分析**，於任何報告頂端呈現。出現 Level 2、TIR < 70%、或多數餐次未於 3 小時內恢復時，提示「與新陳代謝科或內分泌科醫師討論」——僅提示，不建議處置。
