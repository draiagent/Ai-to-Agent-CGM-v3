# Google Workspace 最小設定

## 1. Drive 資料夾

建議結構：

```text
CGM-Coach-v1/
├── raw-meal-images/
├── raw-cgm-exports/
├── processed/
└── reports/
```

原始資料夾應限制寫入與分享，處理程式不得覆蓋原始檔。

## 2. Google 表單欄位

1. 餐點照片（必填）
2. 實際開始進食時間（必填）
3. 餐別（必填）
4. 份量參考（必填）
5. 含糖飲料／醬汁／勾芡（必填）
6. 進食順序（選填）
7. 餐後活動（選填）
8. 睡眠與壓力（選填）
9. 備註（選填）

## 3. Sheets 分頁

- `Meals_Raw`：表單原始回應，只追加不修改。
- `Meals_Confirmed`：使用者確認後的權威資料。
- `CGM_Raw`：原始匯入。
- `CGM_Normalized`：統一時區、單位與欄位。
- `Analysis`：固定程式輸出。
- `Audit_Log`：AI 版本、人工修正與處理時間。

## 4. 自動化事件

表單送出後：

1. 產生 Meal ID。
2. 保存 Drive 檔案參照。
3. 呼叫 Meal Vision Agent。
4. 寫入候選食物與份量區間。
5. 發送待確認狀態。
6. 確認後才進入 CGM 分析佇列。

## 5. 安全最低要求

- 採最小權限，不公開分享原始資料夾。
- API 金鑰使用安全的環境或祕密管理，不寫入試算表及 GitHub。
- 測試與公開示例使用合成資料。
- 設定資料保存期限與刪除流程。
- 所有匯出報告使用去識別代碼。
